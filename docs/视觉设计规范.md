# 未来造物 · AI 赛事时讯 — 视觉设计规范 v1.2

> 风格基调：**苹果式极简** × **未来造物科创**
> 更新日期：2026-10-07 · v1.2 新增第十二节「时效性组件」，Tab「资讯」更名「时讯」

---

## 一、设计原则

1. **内容优先**：界面是赛事的容器，不是展示设计的地方。
2. **一屏一事**：每屏只有一个视觉重心。
3. **单一强调色**：全站只有一个强调色，其余全是灰阶。
4. **精确即装饰**：科技感来自"精确"，不来自发光、渐变、科技纹理。
5. **动效克制**：只做位移与透明度，不做弹跳、发光、粒子。
6. **海报即主角**：赛事海报是第一视觉，界面为它让位。
7. **时效即信任**：产品叫「时讯」，界面上必须**看得见时间的流动**——相对时间、更新角标、核验凭证、变更留痕。看不见更新，就等于没有更新。

### 渐变使用红线

`linear-gradient(135deg, #0A84FF, #7A5CFF)` 只允许出现在三处：

1. 品牌符号
2. 重磅赛事的**海报底**
3. 金额数字描边

**禁止**用于按钮、页面背景、大面积区域、Tab 栏。

## 四、字体与数字语言（科创融入点 ①）

| 场景 | 字体 |
|------|------|
| 中文 | PingFang SC / 苹方 |
| 西文 | SF Pro / `-apple-system` |
| **数字** | **SF Mono / `ui-monospace`，等宽** |

**等宽数字是全案的核心手法。** 倒计时、奖金、日期、报名人数、编号一律用等宽数字。
让"精确"成为视觉语言——比任何科技渐变都更高级，也更像苹果。

### 字号阶梯

| 标题 | 22 / 500 |
| 小标题 | 17 / 500 |
| 正文 | 15 / 400 |
| 辅助 | 13 / 400 |
| 最小 | 11 / 400 |

## 五、间距 · 圆角 · 描边

- **8pt 网格**：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40
- 页面左右安全边距：**20px**
- 圆角：卡片 16 · 按钮 12 · 输入框 12 · 标签 999 · 大容器 20 · 手机屏 40
- 描边：分割线 `0.5px`（小程序用 `1rpx`），色值 `rgba(0,0,0,0.08)`
- **阴影：几乎不用。** 仅浮层允许 `0 8px 32px rgba(0,0,0,0.08)`

## 六、组件规范

### 赛事卡片（海报式）

- 白底 · 圆角 16 · `1rpx` 描边 · **无阴影**
- 结构：**海报封面区** → 标签行 → 元信息行（等宽数字）
- 封面区即海报（见第十一节），高度 122px，横向裁切
- **只有重磅 / 推荐赛事**才允许用蓝紫渐变海报底

### 状态角标

左上角，胶囊（圆角 999），11px：

- 剩 N 天 → 截止红底白字
- 报名中 → 白底半透明 + 绿字
- 已结束 → 深灰半透明 + 白字

### 筛选 chip

- 未选：`rgba(118,118,128,.11)` 底 + 次级文字
- **选中：墨色底 `#1D1D1F` + 白字**（不是蓝色——保持克制）

### 按钮

- 主按钮：造物蓝底 + 白字，圆角 12，高 50
- 次按钮：白底 + `1rpx` 描边 + 墨字

### 倒计时组件（科创融入点 ②）

- 等宽数字，34/500
- 数字之间用细竖线分隔
- ≤ 7 天整体转截止红

## 八、公众号图文规范

- **头图**：品牌符号 + 赛事名，白底黑字，不带花哨背景
- **正文**：白底，字号 15，行高 1.75，段间距 20
- **赛事条目**：缩略海报（左，3:4）+ 编号 `01 / 02 / 03`（等宽）+ 赛事名 + 截止日期（等宽）
- **分隔**：一条 1px 灰线，或品牌符号
- **文末固定**：品牌语 + 小程序卡片

## 十一、赛事海报规范

**海报是赛事的第一视觉，必须采集。**

### 采集要求

| 项 | 要求 |
|----|------|
| 优先级 | 抓取时**必抓**，抓不到则用「生成式海报」兜底 |
| 规格 | 原图转存云存储，宽 ≥ 750px，保留 3:4 及以上比例 |
| 格式 | JPG / PNG / WebP，单张 ≤ 500KB |
| 命名 | `{slug}-{原图URL短哈希}.{ext}`，短哈希用于**海报去重** |
| 二维码 | 海报内二维码**单独裁存一份**，详情页提供「长按识别 / 保存到相册」 |
| 合规 | **版权归原作者所有**，仅用于信息展示；接到投诉立即下架 |

### 展示规则

| 场景 | 展示方式 |
|------|----------|
| 列表卡片 | 横向裁切（高 122px），`object-position: top`，保留海报标题区 |
| 详情页 | **完整竖版海报**（3:4，宽 208px，居中，圆角 16），下方才出现信息 |
| 公众号图文 | 缩略海报（3:4）+ 编号 + 标题 |

### 兜底：生成式海报

抓不到海报时，系统用固定模板生成一张，**绝不用灰色占位图**：

- 底：重磅赛事用品牌渐变，其余用 `#ECECEF` + 工程网格
- 排版：左上 `DEADLINE` + 等宽日期；左下 赛事名 + 主办方；右下 品牌符号水印
- 这套模板本身就是品牌资产，风格统一比图片真实更重要

## 十二、时效性组件（让"更新"被看见）

> 对应《需求梳理》第十一节。时效不是文案，是视觉语言。

### 实时快讯条（首页顶部）

- 白底 · 圆角 12 · `1rpx` 描边 · 高约 40px
- 左：**红点脉冲**（6px 圆点 + 1px 圆环 ping 扩散，2s 循环）——唯一的红色动效，表示"活着"
- 中：最新一条快讯文本，12.5px，单行省略
- 右：相对时间（等宽，11px）如 `16 分钟前`
- 点击进入「时讯」页

### 排序切换（分段控件）

- 容器：`rgba(118,118,128,.1)` 底，圆角 9，内边距 2
- 选项：**最新更新** / **临近截止**
- 选中：白底 + 极轻投影 + 墨字（**不用蓝色**，与 chip 一致）
- 默认 **最新更新**——先让用户看到"发生了什么"

### 时效角标（卡片右上角）

| 角标 | 样式 | 触发 |
|------|------|------|
| `NEW` | 造物蓝底白字，10px 等宽，字距 .7 | 24 小时内新收录 / 更新 |
| `截止变更` | 白底红字 + 红色描边，10px 等宽 | 截止时间被主办方改动 |

- 位置与左上角状态角标对称，**互不重叠**
- 优先级：截止变更 > NEW
- 触发「截止变更」时，卡片元信息里的日期一并**转红**

### 「今日更新 N 更新」

- 列表标题右侧，等宽 11px，`共 N 场 · 今日 M 更新`
- 用数字证明"这里是活的"

### 快讯时间线（时讯页）

- 竖线：左侧 1px `rgba(0,0,0,.08)`，自顶向下，节点处断开
- 节点圆点 7px：自动监测 = 造物蓝描边；重要 = 红填充；人工发布 = 灰描边
- 层级：相对时间（等宽 11px）→ 正文（14px，关键词加粗）→ 来源（11.5px 弱灰）

### 核验凭证（详情页顶部）

- 一行等宽 11.5px：`● 核验于 X 小时前 · 来源站名`
- 蓝点 5px 置于句首
- 若截止被改动，同行右侧追加红字 `截止时间已变更`

### 变更留痕（详情页段落）

- 标题「截止时间变更」
- 正文：`原截止 10.30 → 现截止 11.05`（新日期转红），后附自动同步时间
- **禁止静默改数字**——变更必须以"变更"呈现
